PLAIN mode demo — plain-folder-demo / Plain Folder Demo
===============================

Listed in .upriv/state.json as storage_mode=upriv_plain.

Files here are LITERAL plaintext on the HD/SSD:
  workspace/Plain Folder Demo/

Flow:
  open  → extract Plain Folder Demo.7z to this folder (plaintext)
  edit  → saves stay here in clear until seal
  seal  → new .7z, overwrite this folder, then remove it

Lock uses the open session in RAM. It does not ask for the password.

No encrypted store:
  (no .upriv/vaults/plain-folder-demo/store/)
