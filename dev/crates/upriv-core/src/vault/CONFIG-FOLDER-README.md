# Upriv vault settings
# Configuración de la bóveda de Upriv
# Upriv 保险库设置
# Upriv वॉल्ट सेटिंग

Upriv reads this folder when this export is imported into a new vault. It is not one of the vault's files, and the new vault does not keep it.
Upriv lee esta carpeta al importar esta exportación en una bóveda nueva. No es un archivo de la bóveda, y la bóveda nueva no la conserva.
将此导出文件导入新保险库时，Upriv 会读取此文件夹。它不是保险库中的文件，新保险库也不会保留它。
इस एक्सपोर्ट को नए वॉल्ट में इम्पोर्ट करते समय Upriv यह फ़ोल्डर पढ़ता है। यह वॉल्ट की फ़ाइल नहीं है, और नया वॉल्ट इसे नहीं रखता।

`config.toml` holds the vault's settings, when the export included them.
`config.toml` contiene la configuración de la bóveda, si la exportación la incluyó.
如果导出时包含了保险库设置，它们保存在 `config.toml` 中。
अगर एक्सपोर्ट में वॉल्ट की सेटिंग शामिल थीं, तो वे `config.toml` में हैं।

`workspace.json` holds the file manager layout, when the export included it: open tabs, expanded folders, and view choices.
`workspace.json` contiene el diseño del gestor de archivos, si la exportación lo incluyó: pestañas abiertas, carpetas expandidas y opciones de vista.
如果导出时包含了文件管理器布局，它保存在 `workspace.json` 中：打开的标签页、展开的文件夹和视图选项。
अगर एक्सपोर्ट में फ़ाइल मैनेजर का लेआउट शामिल था, तो वह `workspace.json` में है: खुले टैब, खुले फ़ोल्डर और व्यू के विकल्प।

Importing works without either file. Do not edit them by hand.
La importación funciona sin ninguno de los dos. No los edite a mano.
缺少这两个文件也可以导入。请勿手动编辑它们。
इन फ़ाइलों के बिना भी इम्पोर्ट काम करता है। इन्हें हाथ से न बदलें।
