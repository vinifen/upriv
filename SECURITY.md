# Private vulnerability reports

This file is **how to reach the maintainer in private**. It is not a description of Upriv’s crypto or on-disk layout.

If a report could leak decrypted vault files, weaken unlock/crypto, or speed up password guessing: **do not** open a public issue.

- Email: **contact.viniciusfn@gmail.com**
- Or GitHub **Security → Report a vulnerability** on this repo, if that form is enabled

Include OS, desktop vs mobile, Upriv version or commit, and steps. **Do not** attach live vaults, passwords, or decrypted files.

Ordinary bugs (UI, packaging, docs, crashes that do not leak vault plaintext) can go through [Issues](https://github.com/vinifen/upriv/issues).
